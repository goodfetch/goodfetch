# The product is Goodfetch, with Foxhound for crawling and Collie for browser automation

The framework is named **Goodfetch**, and Automan was its working name until this decision. The research on Automan found it free only on crates.io: npm, the `@automan` scope, PyPI (an active automation framework), the GitHub name and the .com, .io, .ai and .dev domains are taken. It also found live AUTOMAN software marks in Japan, Brazil and Thailand, and a commercial "Automan" selling Playwright and MCP test automation to the same developers ([name research](https://github.com/Jbmanllr/automan/blob/research/name-availability/rnd/research/2026-10-10-name-availability.md)). On 2026-10-11, `goodfetch` was free on crates.io, npm (name and scope), PyPI and GitHub, and `goodfetch.dev`, `.io` and `.sh` had no DNS. The product's two capability families take dog names from the same theme: **Foxhound**, the hound that follows the scent, for crawl and extraction, and **Collie**, the herding dog that works to commands, for browser automation. AI stays cross-cutting and gets no name of its own, because ADRs 0009 to 0014 put it in one engine, used by both families. Decided in [Product name: keep Automan or rename](https://github.com/Jbmanllr/automan/issues/83).

## Considered Options

- **Keep Automan with qualified identifiers** (`@automanhq/*`, PyPI `automanhq`, an `automanhq` org): rejected. Every install line would carry a qualifier, searches would return two other automation projects, and the commercial name would start with a known conflict. Nothing is published yet, so a rename costs only text now.
- **Foxhound and Collie as separate products or binaries**: rejected. ADR 0024 makes one binary and one run state the architecture. The two names sit on top of the engine as namespaces, command groups and docs sections, and change nothing below them.
- **A third dog for AI**: rejected for the reason above.
- **Bloodhound instead of Foxhound**: rejected. It carries the same "follows the scent" idea, but BloodHound is a well-known security tool.

## Consequences

- **Identifiers.** The binary, the CLI command, the Homebrew formula, the crates.io crate, the npm package and the PyPI distribution and import are `goodfetch`. Internal crates are `goodfetch-*`, npm packages sit under `@goodfetch/*`, the GitHub organization is `goodfetch`, the OCI image is `ghcr.io/goodfetch/goodfetch` and the domain is `goodfetch.dev` (`goodfetch.com` has been registered by someone else since 2016). Environment variables start with `GOODFETCH_`, and the sink system columns with `_goodfetch_`.
- **Sub-names never stand alone.** Foxhound and Collie are taken bare on every registry, so they appear only under Goodfetch: in the SDKs as `goodfetch.foxhound` and `goodfetch.collie`, in the CLI as `goodfetch foxhound …` and `goodfetch collie …`, and in the docs as "Goodfetch Foxhound" and "Goodfetch Collie". SAP's Project Foxhound, a Firefox-based browser for data-flow tracking in security research, does a different job; the overlap is accepted because only Goodfetch is filed as a mark.
- **Trademark.** Before the first public release, a professional clearance search covers GOODFETCH, then the word mark is filed in the US and the EU in classes 9 and 42. Counsel decides on the UK. Other countries follow with Goodfetch Cloud, in the Cloud map. The owner approves the fees. If clearance fails, this decision reopens. This settles the filing left open by ADR 0018.
- **Reservation.** The GitHub organization, the npm scope, a PyPI placeholder, the crates.io name and `goodfetch.dev` are claimed by the owner before anyone else can take them. The repository moves into the organization before the first release, and GitHub redirects the old links.
- **Naming in the repository.** The hosted service is Goodfetch Cloud, and the license files name "The Goodfetch contributors" (ADR 0018). The glossary and every ADR use the new name. `rnd/` keeps "Automan" as a record of the R&D, like any other R&D material.
