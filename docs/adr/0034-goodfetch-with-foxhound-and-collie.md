# The product is Goodfetch, with Foxhound for crawling and extraction and Collie for browser automation

The framework is named **Goodfetch**, and Automan was its working name until this decision. The research on Automan found it free only on crates.io: npm, the `@automan` scope, PyPI (an active automation framework), the GitHub name and the .com, .io, .ai and .dev domains are taken. It also found live AUTOMAN software marks in Japan, Brazil and Thailand, and a commercial "Automan" selling Playwright and MCP test automation to the same developers ([name research](https://github.com/goodfetch/goodfetch/blob/research/name-availability/rnd/research/2026-10-10-name-availability.md)). On 2026-10-11, `goodfetch` was free on crates.io, npm (name and scope), PyPI and GitHub, and `goodfetch.dev`, `.io` and `.sh` had no DNS. The product's two capability families take dog names from the same theme: **Foxhound**, the hound that follows the scent, for crawl and extraction, and **Collie**, the herding dog that works to commands, for browser automation. AI stays cross-cutting and gets no name of its own, because ADRs 0009 to 0014 put it in one engine, used by both families. Decided in [Product name: keep Automan or rename](https://github.com/goodfetch/goodfetch/issues/83).

> Amended by [ADR 0084](0084-goodfetch-ships-two-products-collie-and-foxhound-from-one-repository-and-foxhound-contains-collie.md): Goodfetch is the organization and umbrella brand, not the name of anything installed. Collie and Foxhound are its two Products, each installed on its own: Collie drives one browser page and extracts from the page it is on, and Foxhound, which crawls, contains Collie's code.

> Amended by [ADR 0090](0090-products-are-named-goodfetch-collie-and-goodfetch-foxhound-and-share-one-product-version.md): "not the name of anything installed" covers what a person installs to get a Product. Components both Products share keep `goodfetch` names, such as the `goodfetch-sandbox` helper either Product may install for Plugins (ADR 0033).

## Considered Options

- **Keep Automan with qualified identifiers** (`@automanhq/*`, PyPI `automanhq`, an `automanhq` org): rejected. Every install line would carry a qualifier, searches would return two other automation projects, and the commercial name would start with a known conflict. Nothing is published yet, so a rename costs only text now.
- **Foxhound and Collie as separate products or binaries**: rejected. ADRs 0024 and 0002 make one binary and one run state the architecture. The two names sit on top of the engine as namespaces, command groups and docs sections, and change nothing below them.
  > Amended by [ADR 0084](0084-goodfetch-ships-two-products-collie-and-foxhound-from-one-repository-and-foxhound-contains-collie.md): reversed on the research's evidence. Collie and Foxhound are two Products with an executable each, Foxhound's containing Collie's code, built from one repository.
- **A third dog for AI**: rejected for the reason above.
- **Bloodhound instead of Foxhound**: rejected. It carries the same "follows the scent" idea, but BloodHound is a well-known security tool.

## Consequences

- **Identifiers.** The binary, the CLI command, the Homebrew formula, the crates.io crate, the npm package and the PyPI distribution and import are `goodfetch`. Internal crates are `goodfetch-*`, npm packages sit under `@goodfetch/*`, the GitHub organization is `goodfetch`, the OCI image is `ghcr.io/goodfetch/goodfetch` and the domain is `goodfetch.dev` (`goodfetch.com` has been registered by someone else since 2016). Environment variables start with `GOODFETCH_`, and the sink system columns with `_goodfetch_`.
  > Amended by [ADR 0084](0084-goodfetch-ships-two-products-collie-and-foxhound-from-one-repository-and-foxhound-contains-collie.md): the organization's names stay `goodfetch` (the GitHub organization, the npm scope, `goodfetch.dev`, the `ghcr.io/goodfetch/` prefix). Every identifier that names the installed software (the executable, the CLI command, the Homebrew formula, the crates.io crate, the npm and PyPI packages, the OCI image) is renamed per Product in [Product names, packages, executables and version line](https://github.com/goodfetch/goodfetch/issues/457).
  > Amended by [ADR 0090](0090-products-are-named-goodfetch-collie-and-goodfetch-foxhound-and-share-one-product-version.md): the executables, the Rust SDKs' crates.io crates, the PyPI packages and the Homebrew formulas are `goodfetch-collie` and `goodfetch-foxhound`, the npm packages `@goodfetch/collie` and `@goodfetch/foxhound`, and the OCI images `ghcr.io/goodfetch/collie` and `ghcr.io/goodfetch/foxhound`. Internal crates keep `goodfetch-*`, environment variables `GOODFETCH_` and the sink system columns `_goodfetch_`; the engine-path variable names its Product (`GOODFETCH_COLLIE_ENGINE_PATH`, `GOODFETCH_FOXHOUND_ENGINE_PATH`). No package is named `goodfetch`.
- **Sub-names never stand alone.** Foxhound and Collie are taken bare on npm, PyPI and GitHub, so they appear only under Goodfetch: in the SDKs as `goodfetch.foxhound` and `goodfetch.collie`, in the CLI as `goodfetch foxhound …` and `goodfetch collie …`, and in the docs as "Goodfetch Foxhound" and "Goodfetch Collie". SAP's Project Foxhound, a Firefox-based browser for data-flow tracking in security research, does a different job; the overlap is accepted because only Goodfetch is filed as a mark.
  > Amended by [ADR 0084](0084-goodfetch-ships-two-products-collie-and-foxhound-from-one-repository-and-foxhound-contains-collie.md): Collie and Foxhound are product names. Which identifiers carry them, bare or qualified, and how the docs write them, is decided in [Product names, packages, executables and version line](https://github.com/goodfetch/goodfetch/issues/457).
  > Amended by [ADR 0090](0090-products-are-named-goodfetch-collie-and-goodfetch-foxhound-and-share-one-product-version.md): each Product's identifiers are qualified as `goodfetch-collie` and `goodfetch-foxhound` where a namespace is first come, first served (PATH, PyPI, crates.io, Homebrew, import, skill and MCP server names), and bare under the namespaces Goodfetch owns (`@goodfetch/collie`, `ghcr.io/goodfetch/foxhound`). The SDKs' connections are `Collie` and `Foxhound`, and the CLI has no `collie` or `foxhound` command group. Prose outside the project writes "Goodfetch Collie" and "Goodfetch Foxhound" at first mention, then "Collie" and "Foxhound".
- **Trademark.** Before the first public release, a professional clearance search covers GOODFETCH, then the word mark is filed in the US and the EU in classes 9 and 42. Counsel decides on the UK. Other countries follow with Goodfetch Cloud, in the Cloud map. The owner approves the fees. If clearance fails, this decision reopens. This settles the filing left open by ADR 0018.
  > Amended by [ADR 0084](0084-goodfetch-ships-two-products-collie-and-foxhound-from-one-repository-and-foxhound-contains-collie.md): the clearance search also covers COLLIE and FOXHOUND as product names. If it fails for one, that naming reopens as this item provides for GOODFETCH; the boundary between the Products does not.
