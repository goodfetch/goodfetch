# V1 scope matrix

This matrix is the companion of [ADR 0037](0037-v1-scope-parity-and-pain-coverage.md). It gives one status, its source and its `/to-spec` area to every row of the [parity list of 2026-10-10](https://github.com/goodfetch/goodfetch/blob/research/parity-list/rnd/research/2026-10-10-parity-list.md) (Crawlee JS 3.18.2 / 4.0.0-rc.1, Crawlee Python 1.10.4, Spider 2.53.9, Stagehand 4.2.0), to five Stagehand v3 capabilities reached through Crawlee, and to the 24 pains of `rnd/research/market/pains-ranking.md`. A ticket that resolves an `open` row changes that row in its pull request, and the map is done when no row reads `open` and the map has no open ticket. When a pull request changes an `open` row, it also updates the "Waits on" column of ADR 0037.

> Amended on 2026-11-11, from the grilling of decision G-19 of the consolidated review, whose answers ADR 0037's note of that day records: rows were added for the capabilities the compared tools offer, and notes naming a tool were added to rows that already covered its need. Each added row names the compared tools that ship the capability, from the [Compared tools](#compared-tools) table, and its "G-19 ids", the readers' findings it rests on, kept in the grilling's working files outside the repository. An `excluded` row names the question the owner answered and quotes the answer; the questions and answers are recorded in [G-19's record](https://github.com/goodfetch/goodfetch/issues/2474).

> Amended on 2026-11-17, from the re-read of the compared tools before Features' line 1 was cut ([`docs/agents/rollout-order.md`](../agents/rollout-order.md), "How a line is cut"): the [Compared tools](#compared-tools) table moved to each tool's latest release, and the five tools read from docs only were read in code, which confirmed or corrected every "(docs only)" note. Rows were added for the capabilities no row held: `open` where the owner has not decided, each asked in [#2743](https://github.com/goodfetch/goodfetch/issues/2743), and `decided` where an ADR or a ticket already held it. Notes naming a tool were added to rows that already covered its need.
