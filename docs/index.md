# Home

{/* products: collie */}
Goodfetch Collie drives a browser from your program or agent, with a page API shaped like Playwright's, AI actions whose Effects are journaled, and a Verdict on each Run, all on your machine.
{/* end products */}
{/* products: foxhound */}
Goodfetch Foxhound crawls sites politely by default, resumes from Checkpoints, and delivers Records under each Sink's guarantee, with their Completeness reported. Every page it renders is a Goodfetch Collie page.
{/* end products */}
