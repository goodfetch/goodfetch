# Choose a Product

Goodfetch has two Products. One question chooses between them: does your program or agent decide which pages to visit, or does the run discover pages and keep what it gets from each?

- Your program or agent decides: [Goodfetch Collie](collie/index.md).
- The run discovers the pages: [Goodfetch Foxhound](foxhound/index.md).

| Goodfetch Collie | Goodfetch Foxhound |
|---|---|
| Fill a form | Crawl a site |
| Read the page a program reached | Collect Records into a Dataset |
| Let an Agent reach a goal | Deliver them to a Sink |
| Repeat an automation on a Schedule | Track what changed across a crawl's Records |

Foxhound contains Collie, so one program never needs both. Two programs may each use one, and both installed collide nowhere.
