# AI layer with a fake model (D-ai-layer), October 8, 2026

Prototype of the AI layer measured in `local-dev` on committed sources. Retained run: `ai-replay-repair-2026-10-08T18-36-20-202Z-8f0ce3`. Two modes, four page variants, 3 blocks; each session chains 5 executions on the unchanged page then one on the drifted page.

- **Fake model**, OpenAI-compatible, deterministic: it plans from the page observation and counts the tokens of each request itself. The lab compares this count with the agent's; the difference is zero everywhere.
- **Agent on every execution**: observation, model call, actions.
- **Compiled replay**: the first pass compiles a plan with the fingerprint of each target (tag, type, label, text); subsequent passes replay it without the model, after checking the **whole** plan against the page before the first effect. A drift entitles it to a single repair by the model.

- Compiled replay makes one model call per session, plus one repair when the page drifts: 3 to 6 times fewer tokens per verified task than the agent on every execution, without false successes.
- **Silent drift**: the button replaced by "Delete my account" at the same selector is rejected by the fingerprint, then the repair finds the real button; the changed price is re-read live, not served from the plan.
- **Defect found and fixed**: the first version checked the fingerprint step by step. On `decoy-swap`, it had already ticked the consent checkbox when it discovered the drift, and the repair, replaying the plan from the start, unticked it: a wrong booking returned as a success. The plan is now validated in full before the first effect.
