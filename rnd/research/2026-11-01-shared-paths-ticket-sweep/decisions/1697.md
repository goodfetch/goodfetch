# Decision log: spec from #1697 and #1707

## Reversible choices

- **One spec for both issues,** as asked; the outside agent's tickets come last; alternative two specs, which would split the one Proposal list.
- **Order:** tracer with the Scripted model, then the prompt and tools, then Proposals, then compaction and resume, as #1697's brief says, then the AI turn and the outside agent.
- **`proposal.accept` is SDK reach refused to `mcp` and `worker`, not `Reach::PersonOnly`,** since a passkey per accepted change is unusable and an accepted change reaches only a Working copy, which saves under a push's checks; alternative person-only with step-up (#1643), the stricter reading of the brief's "person only". A surface is a claim (ADR 0029), so a person's own SDK program, or an agent scripting that SDK with a member's token, can accept. Least certain decision here. A switch to person-only later is a one-word change in the catalog.
- **A restart reconciles #1696 and #1697:** back as `interrupted`, and a person's `conversation.resume` continues the turn; alternative the brief's bare "resumes mid-turn", which contradicts #1696's "no agent call resumes on its own".
- **The conversation lives in its Session's Run,** so journal, Limits, allowance and Checkpoint come with it; alternative its own store, a second place for all of these.
- **The join credential is a one-use code plus a handle, digests in memory, not a token by Secret reference:** departs from #1707's brief, because a tool-argument token sits in the model's context and the host's transcript and nothing needs to outlive a restart; alternative the brief's token.
- **The profile is chosen when the MCP server starts, not by credential:** departs from #1707's brief ("appear only with a join credential"), because MCP `2026-07-28`'s list endpoints "no longer vary per-connection"; alternative an MCP revision that allows it, which ADR 0070's target isn't.
- **`Reach` gains a value for the join profile,** with `session.join.*` operations for what the agent reads and proposes; alternative `proposal.*` reachable by the agent, which would also put them on other surfaces. A person's and an agent's calls stay apart.
- **`ai_turn` is a new field on `session.control`,** not a new `acting` value as #1707's brief has it, since #1696's draft names `acting` `automation` and an AI's turn with nothing running is still `waiting`; alternative growing `acting`, which #1696's draft allows but which can't say both.
- **`conversation.send` takes a free AI turn itself,** so a plain conversation needs no extra call; alternative an explicit give first.
- **The ten job names** come from #1712's issue and comment; #1712 may rename them before either lands.
- **A tool the Product lacks stays in the list and answers `not_in_product`,** so the cached prefix is one per conversation; alternative a list per Product, which the owner's checklist doesn't need.
- **Check-model jobs ahead of #1716 and #1717 use each tool's plain form;** alternative blocking on them, but they're blocked by this.
- **The defaults of `ai.conversation.enabled` and `session.attended.outside_agents` are on,** because a person must start or issue before anything happens; an operator locks them off; alternative off by default.
- **`ModelUsage` gains its fields on #1349's cache token fields,** as the brief says. Today's protocol type holds only `calls` and `tokens`, so #1349 must land first, and the `prompt` ticket is blocked by it.
- **The 60% bar is asserted on recordings or stubs as a layout check;** real providers' figures are #1712's. No paid call is needed or listed.
- **Blockers added beyond the briefs:** #406, #407, #834, #841, #957, #979, #976, #1015, #1359, #1684, #1127, #1514, #1665, as the parts each ticket reuses. #1710 sits on `prompt`, #1685 and #1698 on `proposals`, and #1708 and #624 on `outside-act`, rather than all on the tracers, so the tracers start sooner.
- **Milestone M4 for every ticket:** #829, #957 and #1349 are M4. #1696, #1689, #1685, #1698, #1710, #1708, #1665 and #1684 have no milestone yet here, and must be at most M4 when set.
- **Moving others' edges, for the publishing session:** #1701 fits on `prompt`, #1715 and #1716 on `page-tools`, #1717 on `more-tools`, #1804 on the tracer, #1712 on `jobs`. They name #1697, and the tracer closes first, so I recommend moving them; otherwise they unblock early. Not done here.
