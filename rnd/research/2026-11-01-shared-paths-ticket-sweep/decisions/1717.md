# Decision log: spec from #1717

## Reversible choices

- **`sample_pages` counts every page, default 15 (5 shown, 10 held out):** 10 held-out pages make 30% exact, as the issue's case needs. Alternative: keep 10 and 5 held out, which reads only 20% or 40%.
- **Held-out split by a seeded shuffle within each URL group, before any model call:** it gives a provable isolation. Alternative: hold back the last pages fetched, which correlates with site order.
- **Ladder rungs CSS and XPath only:** `FieldLocator` reads alike on every Fetch tier. Alternative: ADR 0091's role-and-name rung, which would force a browser.
- **`fallbacks` beside `locator`, not a `Ladder` variant of `FieldLocator`:** no exhaustive match changes and tiers stay untouched. Alternative: a variant, which edits the tier reads and is no clearer.
- **Preview is a returned value the person starts, not a crawl inside the draft:** keeps #1127's "nothing starts" and ADR 0011's review. Alternative: run it in the draft, which breaks both.
- **No start refusal on `needs_review`:** the person reviews, and a declaration is data. Alternative: refuse unless forced, which adds a new flow nobody asked for.
- **Min coverage 0.9 as a setting:** it flags the issue's case and tolerates a rare gap. Alternative: per-field thresholds, premature before #1712's figures.
- **`check_model` and `ai.check.model`, falling back to the model:** the draft stands alone before #1697 exists. Alternative: wait for #1697's settings, which blocks this spec on an owner decision.
- **Not blocked by #1697, #1710 or #1716:** the Scripted and Fake models prove the draft; a real small model is #1712's concern. The closed choice shares #1716's shape, with whichever lands first defining it. Alternative: block, which delays with no gain.
- **No model-written fallback path kept:** pre-release, and the issue replaces how a draft is made. Alternative: a mode, which is an earlier-state shim.
- **Refs on a document are engine-assigned ordinals:** `ai` snapshot refs need a browser. Alternative: always draft on a browser, which reads a different page from what a fetch tier reads.
- **Path check differs from the triage brief on one point:** F1 is touched, since compiled fields run per page in the crawl; the rest of "none" stands.
- **Gate tickets:** `field-ladder` #1846 (F1), `survey-tracer` #1858 (E6), as one per ticket. `first-crawl-no-model` inherits through `held-out-check`, which `field-ladder` blocks by way of `draft-fields`.
- **All tickets M4 Everything else:** #1127 and the rest are M4, and nothing they block is earlier.
- **`draft-site` first, with no blocker:** it proves itself with a wrong and a right answer and lets the frontier start at once.
