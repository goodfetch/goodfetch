# Golden scenarios

[Golden scenarios and the pain coverage matrix](https://github.com/goodfetch/automan/issues/463) decides the scenarios and where the pain coverage matrix lives. Each scenario then gets one description here: the task, the leader it is compared with (Playwright, Stagehand, Browser Use, Crawlee or Scrapy), the leader's version, and the comparison (concepts introduced, lines, failure points). Its programs live in each language's `scenarios/` or `examples/` folder.
