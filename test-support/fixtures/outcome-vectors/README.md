# Outcome vectors

Hand-written data stating the result document's outcome rules (ADR 0063): each file gives what a document holds and the outcome it must get. `goodfetch-protocol`'s constructors pass every file, and the TypeScript and Python helpers that write `journey` documents pass them in their own runners. Never generate them from the code they test.

- `journey/*.json`: `steps` (`passed`, `failed`, `not_reached`, `manual`), `checks` (`passed`, `failed`, `not_reached`), `tasks` (each named task's oracle outcome, `verified`, `incomplete`, `false_success` or `failed`, or `null` when the oracle never answered), optionally `test_errors` (what failed the test outside its steps and checks) and the variant's `outcome` (`proved` or `failed`).
- `conformance/*.json`: one capability's `cases`, each with its `entries` and each entry's `checks` (whether each held), the `case_outcomes` they give (`passed`, `failed`, `not_reached`) and the capability's `outcome` (`proved`, `unproved` or `failed`).

- `journey-comparison/*.json`: a `journey` (its `steps`, each with its `text` and, for a step that needs a person, `manual`; its `expect` checks, each with its `text` and an optional `task`; and the `tasks` it names, in order, as in a Journey file), a `document` stored for it (its `steps` and `checks` with their outcomes, its `tasks` with each oracle `answer` or `null` and, when the answer names another task, `answered`, the stored `outcome`, and, when they are not the Journey's own, the Proving ground `seed` and the `surface`, `cli` otherwise), and what reading it gives: `accepted`, `journey_outcome` (the stored outcome is not the one its contents give), `manual_step`, `answer_of_another_task`, `other_seed`, `unlisted_surface`, or `missing_`, `extra_` or `…_out_of_order` for a `step`, `check` or `task` (`missing_step`, `check_out_of_order`). `goodfetch-protocol`'s `read` and `read_journey_document` pass every file; a helper's documents must read as these say.

Each file has a `description` saying what it shows. A new rule or edge case adds a file.
