# Journey report workspace

A workspace for `xtask journeys report` (ADRs 0058, 0063, 0072 and 0094): a
catalog of both Products' Journeys over two milestones and two areas, a
retired Journey, and the Features and exceptions the owner test's "Journeys
to try" reads. Each test writes the results store it reads, with the result
documents its runs kept.
